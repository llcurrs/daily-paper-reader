## 摘要
合成孔径雷达（SAR）与光电（EO）影像提供互补观测：SAR 可实现昼夜、抗天气影响的感知，而 EO 提供丰富的外观与细粒度语义线索。我们提出 SAREO-FM，避免迫使单一 token 流承担两种不同角色：模态 token 通过掩码重建保留每种传感器对场景的观测方式，而可学习语义查询在预训练视觉基础模型（VFM）的引导下捕获场景包含的内容。通过将这些查询与 SAR 和 EO token 联合编码，查询获得以模态为基础的语义上下文，同时模态 token 输出仍是掩码重建的显式目标。该设计将语义监督与重建监督分配给分离的 token 流，同时保留它们在共享编码器内的交互。在百万规模 SAR-1M 语料库上预训练后，SAREO-FM 对仅 SAR 和仅 EO 输入均取得强单模态迁移，同时在受益于互补感知的任务上，通过联合 SAR-EO 观测带来显著增益。

## Abstract
Synthetic aperture radar (SAR) and electro-optical (EO) imagery provide complementary observations: SAR enables day-and-night, weather-resilient sensing, whereas EO provides rich appearance and fine-grained semantic cues. We introduce SAREO-FM, which avoids forcing a single token stream to serve two distinct roles: modality tokens preserve how each sensor observes the scene through masked reconstruction, while learnable semantic queries capture what the scene contains under guidance from a pretrained vision foundation model (VFM). By jointly encoding these queries with SAR and EO tokens, the queries acquire modality-grounded semantic context, while the modality-token outputs remain the explicit targets of masked reconstruction. This design assigns semantic and reconstruction supervision to separate token streams while preserving their interaction within the shared encoder. Pretrained on the million-scale SAR-1M corpus, SAREO-FM achieves strong unimodal transfer for both SAR-only and EO-only inputs, while delivering substantial gains from joint SAR--EO observations on tasks that benefit from complementary sensing.

# SAREO-FM 论文深度总结

## 1. 核心问题与整体含义

- **背景**：合成孔径雷达（SAR）具备全天时、全天候、抗天气的观测能力，而光电（EO）影像提供丰富的表观纹理与细粒度语义线索，两者在地物分类、目标检测、变化检测、跨模态检索、云去除、SAR-to-EO 翻译等任务中高度互补。因此，一个实用的 SAR–EO 基础模型应当既能从任一单模态学到强表征，又能在成对观测可用时利用互补证据。
- **核心问题**：现有代表性方法（如 SARMAE）让**同一图像 token 流**同时承担两项彼此冲突的职责——一方面要保留模态特有信息以支持像素级掩码重建，另一方面又要与 EO 派生的 VFM 高层语义特征对齐。这种“一流两职”的耦合会直接约束模态特定重建。论文首次明确指出并形式化该矛盾：**语义监督应当施加在哪里，才能让共享语义学习不直接约束模态特定重建？**
- **整体含义**：论文提出 SAREO-FM，将语义对齐与像素重建的“显式目标”分配给**分离的 token 流**，同时保留它们在共享编码器内的信息交互，从而在统一框架下兼顾单模态迁移与跨模态互补。

## 2. 方法论

### 2.1 核心思想
- 采用 MAE 框架，但操作于**三条 token 流**：SAR 图像 token、EO 图像 token、可学习语义查询（semantic queries）。
- **模态 token** → 送入模态专属解码器做掩码像素重建，保留“传感器如何观测场景”。
- **语义查询** → 与冻结 VFM（DINOv3-7B）的 patch 级特征做逐块对齐，捕获“场景包含什么”。
- 语义查询被**排除在重建解码器之外**，从而解耦两类监督的显式目标；但三者仍在共享编码器内通过自注意力交互，梯度联合优化编码器。

### 2.2 关键技术细节

- **统一三流编码器**：
  - SAR/EO 图像分块后经模态专属线性投影 $E_m$，加上共享 2D sincos 位置编码 $p_i$ 与模态嵌入 $a^{\text{enc}}_m$，得到图像 token $y^m_i$。
  - 语义查询 $\mathcal{Q}=\{q_i\}_{i=1}^N$ 与图像 token 共享同一位置网格，加上查询流嵌入 $a^{\text{enc}}_q$ 得到 $e_{q_i}$。
  - 仅可见 token（$\mathcal{V}_m$）与全部查询拼接送入共享编码器 $E$，输出 $\{Z^{\text{vis}}_s, Z^{\text{vis}}_e, Z_q\}$；缺失模态时其 token 序列整体省略。

- **解耦语义监督**：
  - 冻结 VFM 教师 $f_\theta$ 处理干净未掩码 EO 图像，提取 patch token $T=f_\theta(X_e)\in\mathbb{R}^{N\times D_t}$（必要时空间重采样到 $N$ 个查询位置）。
  - 轻量语义投影器 $h_\phi$（两层 MLP）将查询输出映射到教师特征空间。
  - 对齐损失采用**余弦距离**：
    $$\mathcal{L}_{\text{align}}=\frac{1}{N}\sum_{i=1}^{N}\left(1-\frac{h_\phi(z^q_i)^\top t_i}{\|h_\phi(z^q_i)\|_2\|t_i\|_2}\right)$$
  - 模态 token 不被约束去复现 EO-VFM 特征。

- **模态专属掩码重建**：
  - 编码后的可见 token 恢复原位，掩码位置插入可学习 mask token $e_m$，加解码器位置编码与解码器模态嵌入后送入模态专属解码器 $D_m$。
  - 像素损失仅在掩码位置计算：$\mathcal{L}^m_{\text{pix}}=\frac{1}{|\Omega_m|}\sum_{i\in\Omega_m}\|\hat{x}^i_{p,m}-x^i_{p,m}\|_1$。

- **混合模态掩码策略**（四种模式）：
  - (i) 独立掩码（概率 0.35）：两模态掩码独立采样，鼓励细粒度跨模态推理；
  - (ii) 共享掩码（0.35）：两模态同一空间掩码，迫使依赖更广的空间语义上下文；
  - (iii) 完全丢弃 EO（0.15）：仅 SAR 输入，查询仅从 SAR 提取语义；
  - (iv) 完全丢弃 SAR（0.15）：仅 EO 输入。
  - 每个保留模态按 75% 掩码，所有语义查询始终活跃。

- **预训练目标**：$\mathcal{L}=\lambda_s\mathcal{L}^s_{\text{pix}}+\lambda_e\mathcal{L}^e_{\text{pix}}+\lambda_{\text{align}}\mathcal{L}_{\text{align}}$，其中 $\lambda_s=\lambda_e=1$，$\lambda_{\text{align}}=0.5$；系数在对应监督不可用时置零。

- **下游迁移**：丢弃 VFM 教师、语义投影器与重建解码器，仅保留共享编码器。任务头可选择性使用模态 token 特征（mod，单模态 768 维 / 双模态 1536 维）、语义查询特征（sem，768 维）或二者拼接（both，1536/2304 维）。

## 3. 实验设计

### 3.1 数据集 / 场景
- **预训练语料**：SAR-1M，聚合 18 个公开 SAR 数据集，含 1,312,902 张 SAR 图像（其中 1,042,156 张有地理对齐 EO），覆盖 57 类目标/场景、多种 SAR 传感器与极化模式、0.1–60 m 分辨率。
- **下游任务**：
  - SAR 识别：MSTAR、FUSAR-Ship（语料内）、SAR-ACD（主要语料外）；
  - EO 迁移：EuroSAT（EO/SAR 输入）、NWPU-RESISC45、AID（小样本与更高监督）；
  - 成对 SAR–EO：So2Sat LCZ42（单标签）、BigEarthNet-MM（多标签）；
  - 稠密迁移：BRIGHT（灾前 EO + 灾后 SAR 的建筑损毁评估，仅定性）。

### 3.2 Benchmark 与对比方法
- **受控基线**：SARMAE*（官方 ViT-B checkpoint 在完全相同下游协议下复评），两者使用完全相同的 SAR-1M 预训练图像与 DINOv3 教师特征；关键差异在于 SAREO-FM 额外将原始 EO 作为第二模态输入并做联合重建。
- **其他对比**：ResNet-50、Swin Transformer、BEiT、CROMA、SAR-JEPA、SARATR-X、LoMaR、SUMMIT、Copernicus-FM、CoDe-MAE、MaRS、SARMAE（ViT-B/ViT-L）、随机初始化。
- **评测设置**：1/2/5/10/20/40-shot 线性探测、30% 监督端到端微调；端到端微调报告 3 次独立运行均值，线性探测报告 5 次运行均值。

## 4. 资源与算力

- 使用 **4 张 NVIDIA B200 GPU**，约 **390 B200 GPU-hours**。
- 训练 300,000 步，有效 batch size 2,560，AdamW（β=0.9/0.95，weight decay 0.05），15,000 步 warm-up 后学习率峰值 1.5×10⁻³ 并余弦衰减至零，bf16 精度，梯度裁剪 1.0。
- 编码器为 ViT-B/16，输入 256×256，16×16 token 网格，256 个语义查询；教师为冻结 DINOv3-7B；语义投影器为两层 MLP。

## 5. 实验数量与充分性

- **实验规模**：
  - SAR 端到端微调：3 个数据集 × 2 种监督设置（40-shot / 30%）；
  - SAR 冻结小样本：2 个数据集 × 6 个 shot 档位（1/2/5/10/20/40）；
  - EO 冻结小样本：4 个 shot 档位 × 2 种输入（SAR/EO）；
  - 成对 SAR–EO：2 个 benchmark（5-shot）；
  - 稠密定性：1 个（BRIGHT）；
  - 消融：4 级累积组件消融（随机初始化 → Plain MAE → +DINOv3 监督 → +解耦语义监督 → +原始 EO 模态），每项 5 seed、30,000 步预训练。
- **充分性评估**：
  - **较充分**：覆盖单模态/双模态、小样本/高监督、语料内/语料外、线性探测/端到端微调多种维度；消融逐组件验证贡献；附录详细记录了掩码概率（实测频率 0.3506/0.3506/0.1493/0.1494）、序列长度、特征读出维度、组件生命周期等。
  - **客观公平性**：主对比采用 SARMAE* 同协议复评，隔离“原始 EO 输入 + 跨模态学习”这一变量，控制较好；作者明确区分语料内/语料外结论，并指出不对未做源级排除的 benchmark 主张语料外泛化。

## 6. 主要结论与发现

- **解耦语义监督有效**：消融显示，从 Plain MAE 到完整 SAREO-FM，10-shot 平均 OA 提升 9.90 个点（DINOv3 监督 +5.39，解耦 +3.13，原始 EO 模态 +1.38），且两个 benchmark 上均最优。
- **SAR 迁移**：在 6 个受控设置中 5 个取得最佳；FUSAR-Ship 40-shot 提升 1.32 点、30% 提升 0.31 点；MSTAR 分别提升 3.03 和 2.18 点；语料外 SAR-ACD 40-shot 从 68.50% 提升到 78.40%（+9.90 点），但 30% 监督下 SARMAE* 仍高 1.67 点——说明 SAREO-FM 主要改善**标签高效迁移**而非充分适配后的性能。
- **EO 迁移**：EO 输入下在 1/5/10/40-shot 分别超越其冻结 DINOv3 教师 4.90/5.13/3.42/1.70 点，说明模型并非简单复现教师特征，而是通过联合 SAR–EO 上下文与重建对其进行了适配；标签越稀缺增益越大。
- **联合 SAR–EO 迁移**：BigEarthNet-MM 上联合输入达 66.70 micro-AP，优于最佳单模态 2.28 点、DINOv3 EO 基线 1.97 点；So2Sat LCZ42 上 EO 分支超 DINOv3 3.89 点，但加入 SAR 仅带来 0.65 点增益——说明融合收益是**任务依赖**的，并非所有成对 benchmark 都必然提升。
- **稠密定性**：BRIGHT 上联合灾前 EO 与灾后 SAR 能恢复单模态模型漏检的损毁建筑区域。
- **读出策略**：sem（语义查询）在多数场景是最强冻结表征，both 提供任务依赖的补充。

## 7. 优点

- **问题洞察新颖**：首次明确指出“同一 token 流同时服务语义对齐与像素重建”的耦合矛盾，并给出简洁优雅的解耦方案。
- **架构统一**：单一共享编码器即可处理 SAR-only、EO-only、联合 SAR–EO 三种输入，无需模态专属 backbone 或分离推理管线；缺失模态通过空 token 序列自然处理。
- **监督目标分离但信息交互保留**：解耦仅作用于监督头而非编码器计算，三流仍通过自注意力交换信息，兼顾模态特化与跨模态语义。
- **掩码策略设计合理**：四种模式组合独立/共享掩码与完全模态丢弃，同时促进跨模态交互与单模态鲁棒性，且实测采样频率与配置高度吻合。
- **实验控制严谨**：SARMAE* 同协议复评、固定 support 集合、区分语料内/外结论、附录透明记录掩码、序列长度、读出维度与组件生命周期。
- **教师模型规模大且冻结**：使用 DINOv3-7B 提供语义目标，但下游推理不加载教师与解码器，部署成本可控。

## 8. 不足与局限

- **任务覆盖有限**：定量评估仅聚焦图像级分类与多标签识别；稠密预测（BRIGHT）仅为定性、语料内诊断，不构成完整分割 benchmark。
- **配准假设强**：方法假设成对 SAR–EO 已充分配准以支持 patch 级交互与教师对齐；地理错配、成像时间差、云、SAR 叠
