## 摘要
红外-可见光图像融合（IVIF）对于多模态感知至关重要，但协调热特征与纹理特征之间固有的信息差异仍然是一个基本挑战。现有的先验引导方法通常依赖静态约束，这会导致优化冲突，或者利用来自大规模基础模型（如CLIP/DINO）的外部语义先验，这些方法常常无法利用对高保真融合至关重要的内在模态特性。为了解决这些问题，我们提出了P2Fusion，这是一个基于先验引导蒸馏的框架，通过双内在提示重新构建IVIF。我们不是施加硬编码惩罚，而是将图像内在先验、热显著性和空间质量蒸馏到可学习的动态调节器中。具体来说，一种Teach-to-Fuse机制提供双粒度的渐进式指导，并结合门控动态专家重校准（GDER）模块进行解耦特征细化。这种设计使网络能够通过专家特化自适应地调节模态竞争。大量实验表明，P2Fusion在五个主流数据集上达到了最先进的性能。值得注意的是，我们的框架在融合质量方面表现出持续的性能优势，在5个基准上的20个关键评估指标中有14个达到了最先进的结果。此外，它有效地促进了下游感知的鲁棒性，例如在MSRS、M3FD和DroneVehicle上分别实现了+3.2%、+0.5%和+0.9%的mAP提升，用于目标检测。我们的代码将在https://github.com/YiShi99/P2Fusion上公开。

## Abstract
Infrared-visible image fusion (IVIF) is pivotal for multimodal perception, yet reconciling the inherent information disparity between thermal and textural features remains a fundamental challenge. Existing prior-guided methods often rely on static constraints that induce optimization conflicts or utilize extrinsic semantic priors from large-scale foundation models (e.g., CLIP/DINO), which frequently fail to exploit the intrinsic modality characteristics essential for high-fidelity fusion. To address these issues, we propose P2Fusion, a prior-guided distillation-based framework that reformulates IVIF via dual intrinsic prompts. Instead of imposing hard-coded penalties, we distill image-intrinsic priors, thermal saliency and spatial quality, into learnable dynamic regulators. Specifically, a Teach-to-Fuse mechanism provides dual-granularity progressive guidance, coupled with a Gated Dynamic Expert Recalibration (GDER) module for decoupled feature refinement. This design enables the network to adaptively mediate modal competition through expert specialization. Extensive experiments demonstrate that P2Fusion achieves state-of-the-art performance across five mainstream datasets. Notably, our framework demonstrates consistent performance advantages in fusion quality, achieving state-of-the-art results in 14 out of 20 key evaluation metrics across 5 benchmarks. Furthermore, it effectively contributes to the robustness of downstream perception, such as +3.2% mAP on MSRS, +0.5% mAP on M3FD and +0.9% mAP on DroneVehicle for object detection. Our code will be available at https://github.com/YiShi99/P2Fusion

### 1. 核心问题与整体含义（研究动机和背景）

红外-可见光图像融合（IVIF）旨在将红外热辐射信息与可见光纹理细节互补整合，是多模态感知中的关键任务，广泛用于自动驾驶、目标再识别和医学成像等场景。然而，由于缺乏配对真值，IVIF本质上是一个无监督生成任务，性能高度依赖网络结构和损失函数的设计。

现有先验引导方法存在三大类缺陷：
- **静态硬约束方法**（如基于分割掩码或显著图的正则化）迫使网络优先拟合先验分布，牺牲像素级纹理细节；
- **与下游任务联合优化**的方法容易引入多目标冲突，导致视觉质量与任务性能之间难以平衡；
- **外部语义先验方法**（如CLIP/DINO）虽然缓解了硬约束问题，但引入的先验偏离模态本质，且高层语义与像素级重建之间存在粒度不匹配，无法精确指导低层纹理恢复。

因此，论文提出应从图像自身挖掘内在先验，将先验转化为动态、可学习的提示，而非静态外挂约束，从而实现高保真融合与自适应场景调节。

### 2. 方法论：核心思想、关键技术细节

#### 核心思想
提出**P²Fusion**框架，核心哲学是“先验应是内生的、动态的”。通过**Teach-to-Fuse（T2F）**机制，将两个互补的图像内在先验——红外热显著性和可见光空间质量——蒸馏成可学习的动态调节器，取代传统硬编码惩罚项，提供渐进式、双粒度的指导。

#### 关键技术细节

##### （1）双教师提示蒸馏（Dual-Teacher Prompt Distillation）
- **红外显著性教师（IST）**：基于SegFormer-B2在MSRS/FMB训练集上预训练，生成热辐射显著图（行人、车辆为前景），作为红外分支的动态提示；
- **可见光质量教师（VQT）**：基于BRISQUE无参考质量评估器生成全局质量分数，并归一化为空间质量先验（值越高表示纹理可靠性越强）；
- 特征增强方式：`F_m = f_m + Embed(P_m)`，将提示嵌入特征，而不是直接施加损失约束。

##### （2）门控动态专家重校准模块（GDER）
该模块并非用于扩大模型容量，而是作为解耦特征细化器，包含两个功能特化的专家：
- **先验响应模态专家（E_mod）**：显式消费动态提示，强化模态特有显著信息（如热目标、高对比度纹理）；
- **先验无关注意力专家（E_att）**：使用CBAM全局注意力，挖掘先验可能遗漏的长程依赖与细微结构。

门控网络`G(·)`根据局部特征与全局提示的共识计算动态权重：
`F'' = F' + w1·E_mod(F') + w2·E_att(F')`

该机制能自适应调节模态竞争，当专家信息一致时协同增强，分歧时动态平衡，实现“多视角互补、非刚性地细化特征”。

##### （3）优化目标
总损失由感知约束和蒸馏损失组成：
- 梯度损失：`L_grad = ||∇I_fused - max(|∇I_ir|, |∇I_vis|)||_1`
- 强度损失：`L_int = ||I_fused - max(I_ir, I_vis)||_1`
- SSIM损失：`L_ssim = 1 - (ω_ir·SSIM(I_ir, I_fused) + ω_vis·SSIM(I_vis, I_fused))`
- 蒸馏损失：可见光用MSE，红外用BCE对齐显著图

最终：`L_total = λ1L_int + λ2L_ssim + λ3L_grad + λ4L_distill_ir + λ5L_distill_vis`
