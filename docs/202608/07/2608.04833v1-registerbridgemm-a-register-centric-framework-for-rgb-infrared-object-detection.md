## 摘要
RGB-红外（RGB-IR）目标检测得益于可见光与热成像模态的互补信息，但在光照变化、天气变化和杂乱场景下，有效的融合仍然具有挑战性。现有的RGB-IR融合方法常常以表达性强的补丁级交互为代价，换取更轻量但更受限的适应机制。我们通过经验观察发现，预训练寄存器令牌在成对的RGB-IR输入上同时包含模态共享和模态特定信息，这表明它们可以作为跨模态通信的紧凑基础。基于这一观察，我们提出了RegisterBridgeMM，一种以寄存器为中介的融合框架，组织为三阶段寄存器生命周期。聚合阶段保留从预训练中继承的各模态寄存器摘要；桥接阶段执行带有共识残差调节的双向寄存器到补丁读取；投影阶段将所得寄存器摘要转换为对补丁特征的空间自适应校准。这种寄存器路径避免了密集的补丁到补丁跨模态交互，同时保留了预训练的补丁表示。在两个骨干流均冻结的情况下，RegisterBridgeMM在LLVIP、M3FD、DroneVehicle和FLIR-Aligned四个基准上均取得了所评估方法中的最高mAP50-95。

## Abstract
RGB-infrared (RGB-IR) object detection benefits from complementary visible and thermal cues, but effective fusion remains challenging under illumination changes, weather variation, and cluttered scenes. Existing RGB-IR fusion methods often trade expressive patch-level interaction for lighter but more constrained adaptation mechanisms. We empirically observe that pretrained register tokens contain both modality-shared and modality-specific information on paired RGB-IR inputs, suggesting that they can serve as a compact substrate for cross-modal communication. Building on this observation, we propose RegisterBridgeMM, a register-mediated fusion framework organized as a three-stage register lifecycle. Aggregate preserves per-modality register summarization inherited from pretraining; Bridge performs bidirectional register-to-patch reading with consensus-residual regulation; and Project translates the resulting register summary into spatially adaptive calibration of patch features. This register pathway avoids dense patch-to-patch cross-modal interaction while preserving the pretrained patch representation. With both backbone streams frozen, RegisterBridgeMM achieves the highest mAP50-95 among the evaluated methods on all four benchmarks: LLVIP, M3FD, DroneVehicle, and FLIR-Aligned.

## 2. 提出的方法论：核心思想、关键技术细节

### 核心思想
- **RegisterBridgeMM**：一种以register token为中心的RGB-IR融合框架，将整个融合路径组织为**三阶段register生命周期**：**Aggregate（聚合）→ Bridge（桥接）→ Project（投影）**。
- 关键设计原则：**跨模态注意力仅通过register query路由**，patch token只作为只读的key/value，避免密集patch交互，同时保持预训练的patch表示不被破坏。

### 三阶段生命周期详细技术细节

**（1）Aggregate（聚合）阶段**
- 利用冻结的DINOv3双流backbone（两个流共享同一预训练权重，参数完全冻结），register token在每层自注意力中吸收全局上下文，形成各模态自身的紧凑摘要。
- 该阶段无新增模块，完全继承预训练结构，保留观察到的模态共享/特定分区。
- 形式化：r_m,ℓ+1 = SA_ℓ([c_m,ℓ; r_m,ℓ; p_m,ℓ])|_reg

**（2）Bridge（桥接）阶段**——在浅层到中间层{2, 5, 8}注入
- **RWPR（Register-Write Patch-Read，寄存器写入-补丁读取）**：
  - 双向交叉注意力：每个模态的k=4个register query 对另一模态的N个patch做交叉注意力（O(kN)），取代O(N²)的密集patch交互；
  - 两种方向独立参数：ΔR = CA(r_R, p_T, p_T)，ΔT = CA(r_T, p_R, p_R)；
  - 通过sigmoid门控的残差系数α（初始化为0.1）和LayerNorm更新register：ṝ_m,ℓ = LN(r_m,ℓ + α_ℓ·Δ_m)；
  - 三个桥模块共享架构但不共享参数；patch token只读，保持backbone完整。
- **RCRS（Register-Consensus/Residual-Split，寄存器共识/残差分离）**：
  - 将桥接后的寄存器分解为共识分量 c_ℓ = ½(ṝ_R,ℓ + ṝ_T,ℓ) 和模态特定残差；
  - 以可学习标量门β_ℓ（sigmoid激活，初始化为0.5）重新混合：r'_m,ℓ = c_ℓ + β_ℓ(ṝ_m,ℓ − c_ℓ)；
  - 当β→0时收敛到纯共识（丢弃模态特定信息）；β→1时保留原始桥接结果；
  - 该机制将预训练中隐式的共享/特定结构转化为显式可学习的代数分解。

**（3）Project（投影）阶段**
- **MAC（Modality-Aware Calibration，模态感知校准）**：
  - 构建CR摘要向量：s_CR = [c⋆均值; |r_R⋆−c⋆|均值; |r_T⋆−c⋆|均值] ∈ R^(3D)；
  - 通过共享两层MLP Φ(·)和每尺度线性投影W_s生成全局仿射种子（seed）；
  - 以两模态归一化特征之差经1×1卷积生成空间gap代理（spatial gap）；
  - seed与gap相加形成条件场field，经零初始化的仿射头输出每模态的SPADE风格参数(γ, β)；
  - 校准：F̃_m = F_m + α_s(γ_m⊙F̂_m + β_m)，α_s初始化为0.1；MAC在初始化时为恒等映射；
  - 多尺度金字塔逐级融合后送入RT-DETR检测头。

### 关键公式（简要）
- RWPR：Δ_m = CA(r_m, p_opp, p_opp)；ṝ_m = LN(r_m + α·Δ_m)
- RCRS：c = ½(r_R + r_T)；r'_m = c + β(r_m − c)
- MAC：s_CR = [c⋆; |r_R⋆−c⋆|; |r_T⋆−c⋆|] → affine parameters → F̃ = F + α(γ⊙F̂ + β)

## 6. 主要结论与发现

- **预训练register token确实内建了模态共享/模态特定的分区结构**（3+1模式），且该结构可通过训练调节（共享token相似度−0.08，特定token相似度+0.25）。
- **register作为跨模态通信基底有效**：寄存器已训练后对另一模态patch的注意力呈“由粗到细”的高度选择性（层5熵比26% → 层11熵比<1%）。
- **三阶段生命周期设计有效**：完整框架较简单concat融合基线提升**+5.3 mAP_50-95**（LLVIP）。
- **冻结骨干反而略优于微调**（70.5 vs 70.3），表明保留预训练register先验比对其覆写更有价值。
- **四个基准均取得最优mAP_50-95**：M3FD（64.9%）、DroneVehicle（61.5%）、LLVIP（70.5%）、FLIR-Aligned（49.8%），在mAP_50上也全部领先或并列最优。
- **参数效率显著**：仅27.8M可训练参数，远低于Fusion-Mamba（287.6M）、CFT（206.0M）等密集融合方法。
- **RCRS的共识/残差平衡可学习且随深度自适应**——残差占比随层加深而上升（LLVIP：0.6%→5.8%），说明深层寄存器携带的模态特定信息更具判别力。

## 7. 优点

- **新颖的问题切入角度**：从预训练模型内部已有结构出发（register token）设计融合机制，而非在外部添加融合模块，视角独特；
- **强经验动机**：通过预训练诊断实验（3+1分区、跨层熵比）提供了扎实的观察证据支撑设计决策；
- **卓越的精度-效率权衡**：以1/10量级的参数获得超过或持平于密集融合方法的精度，且保持双流骨干完全冻结；
- **保持backbone完整性**：仅更新register token，patch特征流不被污染，有助于保留预训练表示；
- **结构化的多尺度设计**：注入层{2,5,8}与特征提取层{5,8,11}解耦，非最终读出处注入的层位置消融验证了深度读出的选择性不等同于适合作为注入点，设计逻辑严谨；
- **初始化即恒等的增量式设计**：多处门控（α=0.1、零初始化仿射头）保证训练早期不破坏预训练表示，训练稳定性好；
- **跨数据集一致性**：在四种不同场景数据集上均同时提升mAP_50和mAP_50-95，说明改善源于定位与分类质量的整体提升，而非对单一数据集的过拟合。

- **骨干单一下载**：仅验证DINOv3-B/DINOv2-B，未测试更大规模骨干（如Large/Huge）或不同自监督预训练范式下的表现；
