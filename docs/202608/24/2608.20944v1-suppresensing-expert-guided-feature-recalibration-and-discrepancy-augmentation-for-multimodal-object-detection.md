## 摘要
遥感中的多模态目标检测面临语义异质性和模态特定噪声干扰的挑战。为此，我们提出了SuppreSensing，它将多模态融合重新表述为一种选择性协作过程，联合建模共享信息和模态特定线索。SuppreSensing首先设计了一个专家驱动的多模态特征重校准（EMFR）模块，该模块将共享共识提取重新表述为输入自适应的多专家选择过程，以缓解多模态融合中的对称陷阱。作为补充，采用模态特定属性增强策略，通过建模双向差异模式来增强特定模态特征，减轻跨模态异质性。此外，我们提出了一种基于“专项检查-综合分析-诊断更新”体检范式的专家驱动定制特征净化（ECFP）模块，以迭代地过滤冗余并强化任务相关语义。在DroneVehicle和VEDAI数据集上的大量实验表明，SuppreSensing实现了最先进的检测性能。在自然场景数据集（FLIR和LLVIP）上的跨域评估进一步验证了其在多样化环境条件下的卓越鲁棒性和泛化能力。

## Abstract
Multimodal object detection in remote sensing faces challenges due to semantic heterogeneity and modality-specific noise interference. To this end, we propose SuppreSensing, which reformulates multimodal fusion as a selective collaboration process that jointly models shared information and modality-specific cues. SuppreSensing first designs an Expert-driven Multimodal Feature Recalibration (EMFR) module, which reformulates shared-consensus extraction as an input-adaptive multi-expert selection process to alleviate the symmetry trap in multimodal fusion. Complementing this, a modality-specific attribute augmentation strategy is employed to enhance specific modality features by modeling bidirectional discrepancy patterns, mitigating cross-modal heterogeneity. Furthermore, we propose an Expert-driven Customized Feature Purification (ECFP) module based on a "specialized inspection-comprehensive analysis-diagnostic update" physical examination paradigm to iteratively filter redundancies and reinforce task-relevant semantics. Extensive experiments on the DroneVehicle and VEDAI datasets demonstrate that SuppreSensing achieves state-of-the-art detection performance. Cross-domain evaluations on natural scene datasets (FLIR and LLVIP) further validate its superior robustness and generalization capability across diverse environmental conditions.

## 一、核心问题与研究动机

- 论文聚焦**遥感场景下的多模态目标检测**，主要利用可见光（Visible）与红外（Infrared）图像的互补性来提升目标检测能力。
- 遥感图像存在大尺度变化、复杂背景、光照变化与传感器噪声干扰，单一模态难以稳定工作；可见光在低光照/大气扰动下退化严重，红外则在分辨率和细粒度语义上不足。
- 现有主流多模态融合方法大多基于“强对齐假设”（strong alignment），即强制将异构模态映射到统一语义空间，并假设各模态在融合中对称贡献。
- 这种范式会导致“对称性陷阱”（symmetry trap）：
  - 过度语义同质化会抑制红外中的微弱热签名、可见光中的精细纹理等判别性模态特有线索；
  - 在模态退化时，强对齐还会把低质量模态的噪声传播到融合结果中。
- 因此，论文提出**SuppreSensing**，将多模态融合重构为“选择性协作”过程，同时建模**共享信息**与**模态特有线索**，并引入专家机制实现输入自适应的特征重校准与净化。

## 二、方法论

### 1. 整体框架

SuppreSensing 由两大核心模块构成：

- **EMFR（Expert-driven Multimodal Feature Recalibration）**：专家驱动的多模态特征重校准，负责自适应提取共享共识并增强模态特有差异。
- **ECFP（Expert-driven Customized Feature Purification）**：专家驱动的定制化特征净化，基于“体检”范式迭代过滤冗余、强化任务相关语义。

### 2. EMFR 模块

EMFR 包含两个子部分：

**（1）跨模态特征重校准（CFR）**

- 将共享共识提取转化为“输入自适应多专家选择”过程，通过轻量路由器动态激活通道子空间中的专家。
- 具体流程：
  - 输入多模态特征 \(F_s \in \mathbb{R}^{C \times H \times W}\)，其中 \(s \in \{Vis, Inf\}\)；
  - 构建综合表示 \(F = F_{Vis} + F_{Inf}\)；
  - 路由器输出专家权重 \(\boldsymbol{\alpha} = \text{Softmax}(\mathcal{R}(F))\)；
  - 共享共识 \(F_c = \sum_{k=1}^{K} \alpha_k E_k(F)\)，其中 \(E_k\) 为第 \(k\) 个专家；
  - 通过通道注意力 \(\phi(\cdot)\) 生成门控权重 \(G_i = \phi(F_i)\)，并进行交叉门控注入：
    \[
    F_{Inf}^{+} = G_c \times G_{Vis} \odot F_{Inf},
    \quad
    F_{Vis}^{+} = G_c \times G_{Inf} \odot F_{Vis}
    \]
- 这样可根据场景（强光、低光等）自适应调整专家选择策略，避免固定对齐带来的信息损失。

**（2）模态特定属性增强（MAA）**

- 计算双向差异特征：
  \[
  D_{Vis} = F_{Vis} - F_{Inf}, \quad D_{Inf} = F_{Inf} - F_{Vis}
  \]
- 经非线性变换后得到精炼差异特征：
  \[
  F_s^{-} = \phi(D_s) \odot F_s
  \]
- 最终重校准特征为：
  \[
  F_s' = F_s + \lambda^{+} F_s^{+} + \lambda^{-} F_s^{-}
  \]
- 该过程显式保留模态间差异，抑制无关扰动，减轻跨模态异质性。

### 3. ECFP 模块

ECFP 遵循“专项检查–综合分析–诊断更新”的体检范式，将多模态特征分解为五条定制路径：

1. **空间位置定制处方（SLCP）**：
   - 利用 MoE 机制为每个空间位置生成定制化的“处方”；
   - 第一阶段：路由器将主/辅助模态特征拼接为症状表征 \(G_{route}\)，并与冻结的全局正交专家矩阵 \(E\) 做内积，得到匹配权重 \(M = \text{Softmax}(G_{route}E/\tau + \epsilon)\)；
   - 第二阶段：根据匹配权重从可学习知识库 \(P\) 中提取对应专家知识，生成空间定制特征 \(F_{B,S,K} = \sum_K M_{B,S,K} \cdot \hat{P}_{K,S,K}\)。

2. **辅助模态映射（AMM）**：对辅助模态特征做线性+非线性变换，校准其与主模态的语义偏差。

3. **阶段特定主模态投影（SPMP）**：按网络层级深度使用不同投影层，保持跨层语义一致性。

4. **全局静态先验（GSP）**：提供与输入内容无关的各层统计特征，校准跨层分布偏移。

5. **演化主模态（EPM）**：融合前一层诊断更新结果，作为演化基准，实现迭代式特征精炼。

最终通过残差更新主模态特征：
\[
F_{pri}^{(l)} = F_{pri}^{(l-1)} + F_{fus}\left(\text{Concat}\left(F_{EPM}^{(l-1)}, F_{GSP}^{(l-1)}, F_{B,S,K}^{(l-1)}, \hat{F}_{aux}^{(l-1)}, P_{proj}^{(l-1)}\right)\right)
\]

五条路径拼接后作为“综合报告”，经通道维聚合后输入检测头，实现分类与定位。

## 九、整体总结

SuppreSensing 通过对多模态融合中“强对齐范式”的深入反思，提出了一个以“选择性协作”为核心的融合框架。EMFR 利用专家路由实现共享信息与模态特有信息的自适应动态平衡，ECFP 则借助“体检”思想对特征进行定制化净化与迭代精炼。在 DroneVehicle、VEDAI、LLVIP、FLIR 四个数据集上的实验表明，该方法在遥感与自然场景下均取得了令人瞩目的性能提升，且消融实验初步验证了各关键组件的有效性。然而，该研究在计算效率评估、跨检测器泛化、路由机制的可解释性以及实验场景覆盖等方面仍有局限。总体而言，这是一项思路新颖、结构完整、实验较扎实的多模态目标检测研究，为遥感乃至通用多模态感知中的特征融合提供了新视角，但距离实际工程部署仍有待进一步打磨与验证。
