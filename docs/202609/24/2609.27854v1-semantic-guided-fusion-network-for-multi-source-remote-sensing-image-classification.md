## 摘要
多源遥感图像分类因光谱、结构和几何信息的互补性而受到越来越多的关注。然而，现有方法仍存在两个局限：语义上下文建模不足，以及由轻微空间错位导致的不可靠特征融合。为解决这些问题，我们提出了一种用于多源遥感图像分类的语义引导融合网络（SGFNet）。具体而言，设计了语义混合卷积块（SMCB），根据特征表示之间的上下文关系动态生成语义感知卷积核。此外，引入了频率调制融合块（FMFB），在频域中进行跨模态交互，有效缓解轻微空间错位的影响并改善互补信息融合。在 Augsburg 和 Houston 2018 数据集上进行的大量实验表明，所提出的 SGFNet 始终优于若干最先进方法。代码公开于 https://github.com/oucailab/SGFNet 。

## Abstract
Multi-source remote sensing image classification has attracted increasing attention due to the complementary spectral, structural, and geometric information. However, existing methods still suffer from two limitations: insufficient semantic contextual modeling and unreliable feature fusion caused by slight spatial misalignment. To address these issues, we propose a Semantic-Guided Fusion Network (SGFNet) for multi-source remote sensing image classification. Specifically, the Semantic Mixing Convolution Block (SMCB) is designed to dynamically generate semantic-aware convolution kernels according to contextual relationships among feature representations. In addition, the Frequency Modulated Fusion Block (FMFB) is introduced to perform cross-modal interaction in the frequency domain, which effectively alleviates the influence of slight spatial misalignment and improves complementary information fusion. Extensive experiments conducted on the Augsburg and Houston 2018 datasets demonstrate that the proposed SGFNet consistently outperforms several state-of-the-art methods. The codes are publicly available at https://github.com/oucailab/SGFNet .

  1. **语义上下文建模不足**：传统卷积使用空间共享、固定的卷积核，难以适应不同语义结构和内容感知的特征分布。

## 2. 方法论

### 2.1 总体框架

- SGFNet 采用**双分支层次架构**，分别处理 HSI 与 SAR/LiDAR 数据。
- 两个分支先经卷积层提取初步光谱—空间与结构特征。
- 网络由多个堆叠的**语义引导融合模块（SGFM）**组成。每个 SGFM 内部包含：
  - 两个 **语义混合卷积块（SMCB）**，用于建模语义感知上下文表示；
  - 一个 **频率调制融合块（FMFB）**，插入两个分支之间，用于跨模态频域交互。
- 多个 SGFM 逐步实现层次化语义细化与多模态特征融合，最后经两层卷积细化并输出分类结果。

### 2.2 语义混合卷积块（SMCB）

- **动机**：标准卷积核空间共享且固定，无法根据位置和上下文动态调整。
- **关键流程**：
  - 输入特征 \(X \in \mathbb{R}^{C \times H \times W}\)，经 \(1\times1\) 卷积得到 value 特征 \(V\) 和 query 特征 \(Q\)。
  - 同时，\(X\) 经自适应池化与 \(1\times1\) 卷积得到 key 特征 \(K\)。
  - 将 \(Q\) 重塑为 \(\mathbb{R}^{C \times HW}\)，\(K\) 重塑为 \(\mathbb{R}^{C \times K^2}\)，其中 \(K\) 为动态核大小。
  - 计算亲和图 \(A = Q^T K\)，衡量每个空间位置与局部窗口中 \(K^2\) 个采样位置的关系。
  - 经线性层、重塑与 Softmax 生成动态卷积核 \(D\)。
  - 将 value 特征 \(V\) 展开为局部 patch，并用动态核 \(D\) 对每个空间位置的局部邻域进行加权求和，得到动态聚合特征。
  - 另一条分支使用 \(3\times3\) 深度卷积提取局部特征，并与动态聚合特征残差相加，得到最终输出。
- **作用**：实现位置特定的上下文建模，选择性强调语义相关信息，增强全局语义依赖。

### 2.3 频率调制融合块（FMFB）

- **动机**：不同传感器数据存在轻微空间错位，空间域逐像素融合容易失效。
- **关键流程**：
  - 输入 HSI 分支特征 \(F_h\) 与 SAR/LiDAR 分支特征 \(F_x\)。
  - 分别做二维离散余弦变换（2D DCT），投影到频域，得到 \(\hat{F}_h\)、\(\hat{F}_x\)。
  - 计算频域逐元素差 \(\hat{F}_d = \hat{F}_h - \hat{F}_x\)，作为联合表示。
  - 由 \(\hat{F}_d\) 经 \(1\times1\) 卷积生成 query \(Q_d\) 与 key \(K_d\)；由 \(\hat{F}_h\)、\(\hat{F}_x\) 分别生成 value \(V_h\)、\(V_x\)。
  - 计算注意力：
    \[
    F^{attn}_h = \text{Softmax}\left(\frac{Q_d K_d^\top}{\sqrt{d_k}}\right)V_h,\quad
    F^{attn}_x = \text{Softmax}\left(\frac{Q_d K_d^\top}{\sqrt{d_k}}\right)V_x
    \]
  - 将调制后的频域特征经二维逆 DCT 回到空间域。
  - 再经前馈网络（FFN）与残差连接得到输出。
- **理论依据**：频域平移定理表明，小空间平移主要影响相位，而频率能量分布大体保持。因此 FMFB 对轻微跨模态错位比空间域逐像素融合更不敏感。
