## 摘要
在航空RGB-IR目标检测中，有效利用跨模态互补信息对于复杂光照和环境条件下的鲁棒感知至关重要。现有多模态检测器主要关注空域交互或特定频率特征增强，而不同频率分量的跨模态交互模式仍未得到充分探索。此外，光谱差异本身可能同时包含有用的互补线索和不可靠的模态特定响应，这使得不加区分的频率融合并非最优。为解决这些问题，我们提出FoCal，一种用于航空RGB-IR目标检测的频率导向框架。首先，提出频率感知双域校准（FADC）模块，以显式建模频率相关的跨模态交互。低频分量被协同整合为共享的结构共识，而高频分量通过选择性跨模态交换保留模态特定信息。所得频率感知线索进一步传递到原始特征域，以调控跨模态校准。其次，我们引入差异引导光谱调制（DGSM）模块，该模块利用置信度加权的相对幅度差异来刻画跨模态光谱不平衡，并将其转换为有界符号门，用于对联合多模态频谱进行自适应增强、保留或衰减。在DroneVehicle、ESCVehicle和ATR-UMOD上的大量实验证明了FoCal的有效性，分别取得83.5%、54.8%和64.6%的mAP50值。同时，FoCal仅有3.0M参数，在保持领先检测精度的同时达到113.6 FPS，凸显出良好的精度-效率权衡。代码可在{https://github.com/universeliang/FoCal获取。

## Abstract
In aerial RGB--IR object detection, effectively exploiting complementary information across modalities is critical for robust perception under complex illumination and environmental conditions. Existing multimodal detectors mainly focus on spatial-domain interaction or frequency-specific feature enhancement, while the cross-modal interaction patterns of different frequency components remain insufficiently explored. Moreover, spectral discrepancy itself may contain both useful complementary cues and unreliable modality-specific responses, making indiscriminate frequency fusion suboptimal. To address these issues, we propose FoCal, a frequency-oriented framework for aerial RGB--IR object detection. First, a Frequency-Aware Dual-Domain Calibration (FADC) module is developed to explicitly model frequency-dependent cross-modal interaction. Low-frequency components are collaboratively consolidated into a shared structural consensus, whereas high-frequency components preserve modality-specific information through selective cross-modal exchange. The resulting frequency-aware cues are further transferred to the original feature domain to regulate cross-modal calibration. Second, we introduce a Discrepancy-Guided Spectral Modulation (DGSM) module, which characterizes cross-modal spectral imbalance using confidence-weighted relative amplitude discrepancy and transforms it into a bounded signed gate for adaptive enhancement, preservation, or attenuation of the joint multimodal spectrum. Extensive experiments on DroneVehicle, ESCVehicle, and ATR-UMOD demonstrate the effectiveness of FoCal, yielding $\mathrm{mAP}_{50}$ values of 83.5\%, 54.8\%, and 64.6\%, respectively. Meanwhile, with only 3.0M parameters, FoCal achieves 113.6 FPS while preserving leading detection accuracy, highlighting a favorable accuracy--efficiency trade-off. Code is available at {https://github.com/universeliang/FoCal.

## 一、核心问题与研究动机

- **背景**：航空（无人机）场景下的 RGB–IR 目标检测中，可见光依赖外部光照，在低照度、强光干扰和恶劣天气下细节与对比度严重退化；红外传感器捕获热辐射，对光照变化不敏感，能提供互补的轮廓与结构线索。因此 RGB–IR 多模态融合是实现全天候鲁棒感知的有效范式。
- **现有方法的局限**：
  - 多数方法仅在**空间域**做跨模态交互（语义对齐、注意力聚合等），无法区分结构信息与细粒度模态依赖响应。
  - 近期工作引入**频率域分解**，但对不同频段只是"分解后分配不同的增强算子"，忽略了一个更根本的问题：**不同频段的跨模态分量是否应遵循相同的交互模式**。
  - 频谱差异本身既可能包含有用的互补线索，也可能包含不可靠的模态特定响应，**不加区分地融合并非最优**。
- **核心论点**：
  - 低频分量编码粗轮廓、目标布局、大尺度结构，跨模态对应性强 → 适合**共识形成（many-to-one）**。
  - 高频分量含细边缘、局部纹理、模态依赖响应与传感器噪声，过早坍缩会损失模态特有细节或传播不可靠响应 → 需要**保持个性的二对二交换**。
  - 频率域交互不应是融合的终点，而应作为**估计跨模态交互可靠性的辅助空间**，其结果回传原特征域用于校准信息注入。

## 二、方法论

### 2.1 整体框架
- 在 Ultralytics 单模态框架基础上扩展为双流多模态架构：Backbone 特征提取 + PAN 多尺度融合 + Detection Head。
- 引入**冗余减少（RR）策略**：模态特定分支只保留到 P4，P5 由融合后的 P4 经无参数下采样 + 高层语义编码共享生成；预测集中在 P4/P5 两尺度，P3 仍参与双向多尺度聚合提供细粒度空间线索。

### 2.2 FADC：频率感知双域校准

**（1）频率分解**
- 用 Haar 基 DWT 将每个模态特征分解为低频近似 $A$ 和水平/垂直/对角三个高频分量 $H_h, H_v, H_d$。
- 三个方向高频分量聚合为单一 $H_m$，得到每模态的低频 $A_m$ 与高频 $H_m$。

**（2）低频共识形成（many-to-one）**
- 将 RGB 与 IR 低频分量拼接，经轻量卷积门控 + Softmax 得到互补权重 $\eta_{rgb}, \eta_{ir}$（和为 1）。
- 共享结构锚：$A_{shared} = \eta_{rgb}\odot A_{rgb} + \eta_{ir}\odot A_{ir}$，避免退化为固定平均，可按局部观测质量动态调整贡献。

**（3）高频选择性交换（two-to-two）**
- 对两模态高频做通道平均/最大池化得空间描述子，联合编码为两个**模态特定接收掩码** $M_{rgb}, M_{ir}$。
- 更新：$\tilde{H}_{rgb} = H_{rgb} + M_{rgb}\odot H_{ir}$，$\tilde{H}_{ir} = H_{ir} + M_{ir}\odot H_{rgb}$。
- 关键点：掩码刻画的是**接收方**的接收偏好而非源模态的显著度（recipient-conditioned），防止模态过早坍缩与噪声跨模态传播。

**（4）重组与频率引导可靠性校准**
- 重组：$\tilde{X}_{rgb} = A_{shared} + \tilde{H}_{rgb}$，$\tilde{X}_{ir} = A_{shared} + \tilde{H}_{ir}$，即共享低频锚 + 各自校准的高频细节。
- 频率条件特征不直接作为最终融合结果，而是导出空间权重 $W_s$ 与通道权重 $W_c$，组合为 $W = W_s \odot W_c$。
- 原始 RGB/IR 特征联合编码得双模态上下文先验 $O_{joint}$；校准掩码 $R_k = O_{joint} \odot W_k$。
- 跨模态信息选择性注入：$X^{aug}_k = X_k + R_k \odot X_{\bar{k}}$（$\bar{k}$ 为对侧模态）。
- 进一步构造可靠性参考 $X^{ref}_k = X^{aug}_k \odot R_k$，$\Delta X_k = X^{ref}_k - X^{aug}_k$，最终残差校准 $X^{out}_k = \sigma(\Delta X_k)\odot X^{aug}_k + X^{ref}_k$。

### 2.3 DGSM：差异引导光谱调制

- **差异分支**：共享投影 $P(\cdot)$ 将两模态映射到公共比较空间（训练时联合归一化以降低模态尺度偏差），经正交归一化 FFT 得幅度谱 $A_{rgb}, A_{ir}$。
  - 尺度归一化相对谱差异：$D_{rel} = \frac{|A_{rgb}-A_{ir}|}{A_{rgb}+A_{ir}+\epsilon}$。
  - 能量置信：$E = \frac{A_\Sigma}{\text{Mean}_\Omega(A_\Sigma)+\epsilon}$，$C_e = \frac{E}{1+E}$，最终描述子 $D = D_{rel}\odot C_e$，抑制近乎无响应位置的不可靠差异。
  - 有界符号门：$G_d = \tanh(\mathcal{G}_d(D)) \in [-1,1]$，允许模型学习对差异的正/负响应。
- **主融合分支**：拼接两模态并压缩为紧凑联合表示 $X_{joint}$，FFT 得 $Z_{joint}$。
- **调制与重建**：$Z_{mod} = Z_{joint}\odot(1+\gamma G_d)$，$\gamma=0.5$ 控制最大调制幅度；将复谱转为实值 $Q=[Re, Im]$，经轻量谱变换 $\Phi(\cdot)$ 残差处理 $Q_{out}=Q+\Phi(Q)$，逆 FFT 回空间域并残差连接。
- **设计哲学**：差异估计与内容融合解耦——差异仅作为**控制信号**，而非直接注入信息，从而利用互补谱差异同时降低放大模态噪声的风险。
