## 摘要
近期地球观测表征学习的进展能够处理异构传感器和缺失观测，但通常依赖更大的架构。我们提出 MEOX（Multimodal Earth Observation with eXperts，多模态地球观测专家模型），一种多模态掩码自编码器，编码器参数量为293.9万，总参数量为311.5万。传感器特定适配器、显式有效性信号和共享稀疏专家模块在学习到的逐块融合之前保留模态相关处理。随后，四个元数据标记与单一空间序列一同经过另外十四个编码器模块。共享专家投影配合私有低秩残差限制了参数增长，而旋转注意力支持不同于预训练的下游空间网格。该模型使用模态平衡的掩码重建和结构化传感器丢弃，在122.8万个MMEarth64样本上进行预训练。冻结迁移在64和224像素两种分辨率下的六个GEO-Bench任务上评估。该模型在64像素腰果分割上达到64.42%的平均交并比，在224像素EuroSAT上达到90.56%的平均准确率，超过了相应已报道的CSMoE结果。BigEarthNet微调达到72.95%的微平均精确率。路由诊断能够区分专家参与、空间依赖、模态关联和功能贡献。在留出的WorldCover探针上测得元数据带来0.64个百分点的增益，而检索将同传感器语义与跨传感器对齐区分开来。这些结果表明，在紧凑参数预算下可实现传感器灵活的表征学习和强大的任务迁移。

## Abstract
Recent advances in Earth Observation representation learning accommodate heterogeneous sensors and missing observations, often through larger architectures. We present MEOX (Multimodal Earth Observation with eXperts), a multimodal masked autoencoder with a 2.939 million-parameter encoder and 3.115 million parameters in total. Sensor-specific adapters, explicit validity signals, and a shared sparse-expert block preserve modality-dependent processing before a learned patch-wise fusion. Four metadata tokens then accompany a single spatial sequence through fourteen further encoder blocks. Shared expert projections with private low-rank residuals constrain parameter growth, while rotary attention supports downstream spatial grids different from pretraining. The model is pretrained on 1.228 million MMEarth64 samples using modality-balanced masked reconstruction and structured sensor dropout. Frozen transfer is evaluated on six GEO-Bench tasks at both 64 and 224 pixels. The model reaches 64.42% mean intersection-over-union on cashew segmentation at 64 pixels and 90.56% average accuracy on EuroSAT at 224 pixels, exceeding the corresponding reported CSMoE results. BigEarthNet finetuning reaches 72.95% micro-average precision. Routing diagnostics distinguish expert participation, spatial dependence, modality association, and functional contribution. A held-out WorldCover probe measures a 0.64-percentage-point benefit from metadata, while retrieval separates same-sensor semantics from cross-sensor alignment. These results demonstrate sensor-flexible representation learning and strong task transfer using a compact parameter budget.

- **背景**：地球观测（EO）基础模型需要处理异构传感器（光学 Sentinel-2、SAR Sentinel-1、环境元数据），但实际输入几乎从不完整——光学波段在不同档案间不一致、雷达采集几何多变、元数据可能缺失、下游任务可能要求不同空间网格。
- **核心矛盾**：一个可复用的编码器必须能够区分"缺失值"与"有效的数值观测"（如归一化均值恰为 0 的有效像素），同时还要在有限硬件与大规模档案处理场景下控制模型大小与推理成本。
- **现有方法的不足**：近期 EO 模型（CROMA、DOFA、AnySat、TerraMind 等）通过扩大架构来获得多模态灵活性；稀疏 MoE 虽提供条件计算，但稀疏性本身并不保证紧凑存储或有用的专家专门化——专家可能"活跃但功能相似"，聚合概率平衡也可能掩盖离散调度不平衡。
- **本文定位**：提出一个互补问题——**在仅数百万参数的编码器中能保留多少这种灵活性**。MEOX 将 Geo-MoE-MAE 从 Landsat 元数据感知自编码器扩展为 S1/S2 表示学习器，其定义性选择是**延迟的、有效性感知的融合**。

## 2. 方法论

### 2.1 核心思想
- 三个传感器各自独立经过同一个共享 transformer-MoE 块（保留传感器相关路由机会），之后通过逐 patch 学习权重融合成单一空间序列，再由 14 个编码器块处理。避免将多模态序列全程并行携带，从而控制计算量。
- 三个关键设计支柱：**显式缺失性建模**、**部分共享的稀疏专家**、**轴向 RoPE**。

### 2.2 输入与缺失性建模
- 传感器集合 M，可用子集 A；光栅 Xm ∈ R^{B×Cm×H×W}，有效性掩码 Vm 同形状。
- 波段名映射到配置的物理顺序，波段存在向量 rm 标记可用通道；缺失元素仅在保留有效性后数值零填充。
- **Patch token 构造**（式 1）：tm,i = Am(Xm)i + Qm(Vm)i + ϵm + Rmrm，其中 Am 为卷积适配器内容嵌入，Qm 嵌入有效性掩码（初始化为零），ϵm 为传感器标识，Rmrm 编码波段存在性。
- **元数据 token**（式 2）：纬度、经度、月份（各用 sin/cos 两分量）与 ERA5 气候上下文（12 个温/降水变量），每个 token 由值投影、类型嵌入和显式缺失状态 ϵmiss 组成，缺失时给出"缺失表示"而非"零值"。
- 配置：S2 13 波段，S1 升/降轨各 VV/VH；64×64 图像、P=4 时每传感器产生 256 个 token，宽度 d=144。

### 2.3 共享传感器处理与延迟融合
- 各传感器独立经同一块：zm = Fθ(tm)，参数共享但序列分开处理，注意力与路由在融合前按传感器观察运行。
- **融合分数**（式 3）：am,i = w_f^T LN(zm,i) + cm + log(max(qm,i, 1e-6))，其中 qm,i 为 patch 内有效元素比例，作为有效性先验（全有效为 0，越缺失越负）。
- **融合权重**（式 4）：αm,i = softmax(am,i)，zi = Σ αm,i zm,i；未提供的传感器被排除，wf 与 cm 初始化为零使同等有效传感器初始等权。
- 融合后加入 4 个元数据 token 与 CLS，再经 14 个块；深度编码器只处理一条空间流，token 长度为 Nvis+5（预训练）或 N+5（推理），而非拼接方案的 3Nvis+5 / 3N+5。

### 2.4 紧凑稀疏专家
- 层 0–4 有 3 个专家，层 5–9 有 4 个，层 10–14 有 5 个；专家隐藏宽度从 144 递减至 72，token 宽度保持 144，8 个注意力头。
- **路由**：清洁 logit ℓ(x)=Wr x + br，输入相关噪声尺度 s(x)=softplus(Ws x+bs)+δ；训练时 ˜ℓ(x)=ℓ(x)+η⊙s(x)，推理时确定性。
- **Top-2 选择**（式 5、6）：只对选中的两个专家计算门控权重（和为 1），两个专家都被执行；无容量上限，不丢弃 token。
- **专家结构**（式 7、8）：SwiGLU FFN，其中值投影 Wv 与输出投影 Wo 在层内所有专家间共享，每个专家额外携带两个 rank-8 私有低秩残差路径（Uv,e Dv,e 与 Uo,e Do,e），U 矩阵初始化为零。投影仅在层内共享，层间独立。

### 2.5 位置编码与重建解码器
- **轴向二维 RoPE**：在注意力中对 query/key 做旋转，使用运行时 patch 坐标，残差流中不加入绝对位置向量，从而避免直接向路由器注入位置输入，并支持不同下游网格（要求图像尺寸可被 P 整除，支持矩形输入）。
- 预训练时 75% 空间 patch 被掩码，索引跨传感器共享；编码器可见 64 个 patch（64 像素时）。
- 解码器：post-norm 输出投影到宽度 108，恢复可见位置，掩码 token 填充；两个稠密 transformer 块（RoPE、SwiGLU 隐藏宽度 54、独立传感器头），**176,096 参数，占完整模型的 5.65%**，无 MoE、无跨注意力捷径。

### 2.6 预训练目标
