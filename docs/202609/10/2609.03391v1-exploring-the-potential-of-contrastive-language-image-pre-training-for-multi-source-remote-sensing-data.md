## 摘要
对比语言-图像学习（CLIP）已成为遥感视觉-语言理解的关键范式。然而，现有遥感对比学习方法大多建立在面向RGB的CLIP架构之上，难以利用SAR、多光谱成像（MSI）和高光谱成像（HSI）等异构传感器。为解决这一局限，我们提出OmniRSCLIP，一个支持多源传感器输入的端到端对比学习框架，用于遥感视觉-语言建模。其核心思想是在不破坏预训练视觉知识的前提下，将CLIP扩展到固定的RGB输入接口之外。为此，OmniRSCLIP引入光谱-空间基分解（SSBD），将任意通道自适应建模为基重组问题：预训练CLIP图像块嵌入提供可迁移的空间基，而以波长为条件的系数在受限视觉先验空间内张成传感器特定的嵌入核。该设计避免将异构传感器强制纳入固定通道输入空间，同时在统一的图像-文本语义空间中对齐它们。我们进一步提出一种光谱上下文感知的基于掩码的对比学习方案，以抑制模态特定的冗余特征并增强细粒度图像-文本对齐。最后，为支持多模态训练，我们构建了OmniRS5M，这是首个覆盖RGB、SAR、MSI和HSI的大规模遥感图像-文本语料库。在检索、零样本分类和语义定位上的实验表明，OmniRSCLIP在保持强大RGB域性能的同时，有效将CLIP扩展到异构遥感模态。

## Abstract
Contrastive language-image learning (CLIP) has become a key paradigm for remote sensing vision-language understanding. However, existing remote sensing contrastive learning methods are mostly built on RGB-oriented CLIP architectures, making it difficult to exploit heterogeneous sensors such as SAR, multi-spectral imaging (MSI), and hyperspectral imaging (HSI). To address this limitation, we propose OmniRSCLIP, an end-to-end contrastive learning framework that supports multi-source sensor inputs for remote sensing vision-language modeling. The key idea is to extend CLIP beyond its fixed RGB input interface without breaking the pretrained visual knowledge. To this end, OmniRSCLIP introduces Spectral-Spatial Basis Decomposition (SSBD), which formulates arbitrary-channel adaptation as a basis recomposition problem: pretrained CLIP patch embeddings provide transferable spatial bases, while wavelength-conditioned coefficients span sensor-specific embedding kernels within a constrained visual prior space. This design avoids forcing heterogeneous sensors into a fixed-channel input space, while aligning them in a unified image-text semantic space. We further introduce a spectral-context-aware mask-based contrastive learning scheme to suppress modality-specific redundant features and enhance fine-grained image-text alignment. Finally, to support multi-modal training, we construct OmniRS5M, the first large-scale remote sensing image-text corpus covering RGB, SAR, MSI, and HSI. Experiments on retrieval, zero-shot classification, and semantic localization show that OmniRSCLIP preserves strong RGB-domain performance while effectively extending CLIP to heterogeneous remote sensing modalities.

## 2. 方法论
- **核心思想**：将任意通道适配建模为“基重组”问题，而不是直接预测完整嵌入核或把非 RGB 数据强制投影到 RGB。预训练 CLIP 图像块嵌入提供可迁移空间基，波长条件系数在受限视觉先验空间内生成传感器特定嵌入核。
- **SSBD（光谱-空间基分解）关键流程**：
  - 原始 CLIP patch embedding 为 \(W_{clip}\in\mathbb{R}^{D\times3\times K\times K}\)。先对 RGB 通道维平均池化，得到光谱无关空间原型 \(B_{base}\)。
  - 在 \(B_{base}\) 上加入小扰动，构造 \(N\) 个可学习空间基 \(B_n\)，使初始化锚定在 CLIP 先验空间。
  - 对输入各通道中心波长 \(\lambda_i\) 做正弦位置编码，再经轻量残差 MLP 得到光谱 token。
  - 加入可学习 spectral query，输入 Transformer 编码器，建模波段间依赖，得到全局光谱上下文 \(h_s\) 和各波段上下文表示 \(h_i\)。
  - 通过线性层预测基混合系数 \(\alpha_i(\lambda)\in\mathbb{R}^N\)。
  - 合成第 \(i\) 个通道的图像块嵌入核：\(W_i=\sum_{n=1}^{N}\alpha_{i,n}(\lambda)B_n\)，并做均值-方差归一化。
  - 任意通道图像经通道卷积响应求和得到嵌入特征 \(Z=\sum_{i=1}^{C}X_i\circledast \widehat{W_i}\)，直接送入 CLIP 视觉骨干。
- **光谱上下文感知掩码对齐**：
  - 扩展 Mask-based alignment，将文本特征 \(T\) 与 SSBD 产生的光谱 token \(h_s\) 共同输入 Mask Network，生成文本-光谱上下文感知掩码 \(m=\sigma(G_{mask}(T,h_s))\)。
  - 保留掩码值大于 0.5 的视觉特征，抑制模态冗余，增强细粒度图像-文本对齐。
  - 训练目标：\(L=\lambda_{align}(L_{sidm}+L_{dism})+\lambda_{sparse}L_{sparse}\)，其中 \(\lambda_{align}=10\)，\(\lambda_{sparse}=2\)。
- **语言分支与训练策略**：
  - 使用 KPS 将文本上下文长度从 77 扩展到 248 token，支持长遥感描述。
  - 两阶段训练：第一阶段仅 RGB 图文对，第二阶段加入多模态数据；每阶段 5 epoch。
  - 全局 batch size：第一阶段 1024，第二阶段 384；视觉/文本编码器学习率第一阶段 \(1\times10^{-4}\)，第二阶段 \(1\times10^{-5}\)；Mask Network 保持 \(1\times10^{-3}\)。

## 6. 主要结论与发现
- OmniRSCLIP 在保持 RGB 域强性能的同时，有效将 CLIP 扩展到 SAR、MSI、HSI 等异构遥感模态。
- 多源检索中，OmniRSCLIP 平均 Recall@1 优于 LongCLIP 和 HiMoCLIP；ViT-B/16 平均 33.18，ViT-L/14 平均 33.53。

- SSBD 相比 PCA 和 DOFA 更能利用光谱信息；保留 CLIP 先验初始化可稳定提升性能。
- Mask Network 与 SSBD 互补，联合使用在多模态上取得最佳平均表现。
- 空间基数量并非越多

越好，而是呈现先增后饱和的趋势：1 个基明显不足，16–48 个基逐步提升，64 个基达到性能与参数复杂度的较优平衡，继续增加到 128 个基未带来稳定增益，甚至可能因参数冗余、优化难度上升或过拟合而收益下降。因此论文将 64 个空间基作为默认配置。
- 长文本建模对遥感图文对齐具有实际价值：KPS 将文本长度扩展至 248 token 后，更适配遥感场景中细节丰富、关系复杂的长描述。
- 光谱 token 参与掩码生成后，模型能够根据文本语义和传感器光谱上下文共同筛选视觉特征，减少跨模态冗余，提升细粒度对齐能力。

## 7. 局限与潜在改进方向
- **模态数据规模不均衡**：OmniRS5M 中 RGB 数据约 4.32M，而 SAR、MSI、HSI 分别约为 236.13K、71.87K、47.71K，非 RGB 模态仍属相对稀缺。这可能限制模型在 SAR/MSI/HSI 上的泛化上限，也使多源结论部分依赖 RGB 主域性能。
- **零样本分类未覆盖异构模态**：零样本分类实验集中在 AID、WHU-RS19、OPTIMAL-31、RS-C11 等 RGB 数据集，尚未验证 SAR、MSI、HSI 上的零样本分类能力，因此“多源统一”在分类任务上的证据不如检索任务充分。

- **依赖波长元数据**：SSBD 使用各通道中心波长生成光谱条件系数。若实际数据缺少准确波长信息，或波段定义与训练分布不一致，可能影响任意通道适配效果。

## 8. 总体评价与启示
- **主要贡献**：论文将 CLIP 的 patch embedding 从固定 RGB 三通道扩展为“空间基 + 光谱条件系数”的可重组形式，在保留 CLIP 视觉先验的同时支持任意通道输入；并构建了覆盖 RGB、SAR、MSI、HSI 的大规模遥感图文语料 OmniRS5M。
- **方法价值**：SSBD 不是简单地把非 RGB 数据投影到 RGB，也不是直接预测完整卷积核，而是在 CLIP 先验空间内生成传感器特定嵌入核，这一设计兼顾了迁移性、灵活性与参数效率。
- **实验证据**：多源检索、RGB 检索、零样本分类、语义定位和多项消融共同支撑了核心论点，尤其是 SSBD、Mask Network、CLIP 先验和空间基数量的消融较有针对性。
- **需谨慎解读之处**：由于非 RGB 数据规模有限、零样本分类未覆盖异构模态、语义定位仅定性、训练成本未完整披露，OmniRSCLIP 的绝对优势应结合数据规模与任务设置理解。
- **总体结论**：OmniRSCLIP 为多源遥感视觉-语言预训练提供了一个可行且较系统的范式，说明在保持 CLIP 先验的条件下，通过光谱-空间基分解和光谱上下文感知对齐，可以较有效地统一 RGB、SAR、MSI、HSI 等异构遥感数据。其实践意义在于推动遥感 CLIP 从“RGB 中心”走向“多传感器统一”，但距离完全公平、可复现、低成本、全任务验证的多源遥感基础模型仍有改进空间。
